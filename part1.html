Werkzeug I

Drei Operatoren — und was sie ausrechnen

Alle vier Gleichungen benutzen nur den Nabla-Operator ∇ = (∂/∂x, ∂/∂y, ∂/∂z), angewandt auf drei Arten. Das ist die gesamte Mathematik, die man aus der Vektoranalysis mitbringen muss. Jeder Operator kommt hier zuerst im Bild, dann als Formel und dann an einem konkreten Feld durchgerechnet — bevor er in den Gleichungen auftaucht.

Gradient ∇φ

∇φ = (∂φ/∂x, ∂φ/∂y, ∂φ/∂z)

Auf ein Skalarfeld angewandt, ergibt ein Vektorfeld: zeigt in Richtung des steilsten Anstiegs, senkrecht zu den Niveaulinien.

Divergenz ∇·F

∇·F = ∂Fx/∂x + ∂Fy/∂y + ∂Fz/∂z

Auf ein Vektorfeld angewandt, ergibt ein Skalar: misst, wie stark ein Punkt Quelle oder Senke ist.

Rotation ∇×F

(∇×F)_z = ∂Fy/∂x − ∂Fx/∂y

Ebenfalls ein Vektor: misst die Wirbelstärke. Die x- und y-Komponente folgen zyklisch (x→y→z→x).

∇ = (∂/∂x, ∂/∂y, ∂/∂z) ∇φ Skalarfeld → Vektorfeld "steilster Anstieg" ∇·F Vektorfeld → Skalarfeld "Quellstärke" ∇×F Vektorfeld → Vektorfeld "Wirbelstärke" Rotation ausgeschrieben als Determinante: x̂ ŷ ẑ ∇×F = ∂/∂x ∂/∂y ∂/∂z Fx Fy Fz

Die Determinantenschreibweise ist nur eine Merkhilfe — entwickelt man sie nach der ersten Zeile, fallen genau die drei Komponenten heraus, die unten in den Beispielen einzeln ausgerechnet werden.

Gradient

Skalarfeld φ(x,y,z) = x²y + yz³
∂/∂x∂φ/∂x = 2xy  (y und z sind dabei Konstanten)
∂/∂y∂φ/∂y = x² + z³
∂/∂z∂φ/∂z = 3yz²
∇φ = (2xy, x² + z³, 3yz²)
bei (1, 2, 3): (4, 28, 18)

Der ganze Trick der partiellen Ableitung: Man leitet nach einer Variablen ab und behandelt die anderen wie Zahlen. Bei ∂φ/∂x ist yz³ ein konstanter Summand und fällt weg; x²y wird zu 2xy.

Der Betrag |∇φ| ist die Steigung in der steilsten Richtung, die Richtung von ∇φ steht senkrecht auf den Flächen φ = const. Will man die Steigung in einer beliebigen Richtung û wissen, projiziert man: dφ/ds = ∇φ·û. Bei (1,2,3) in Richtung û = (1,0,0) sind das 4, in Richtung û = (0,1,0) sind es 28 — dort geht es also deutlich steiler bergauf.

Divergenz — Quelle oder quellenfrei?

Zwei Felder mit sichtbar unterschiedlichem Verhalten.

Radialfeld

F = (x, y, z) — zeigt überall vom Ursprung weg
∇·F = ∂x/∂x + ∂y/∂y + ∂z/∂z
∇·F = 1 + 1 + 1 = 3

Konstant positiv — jeder Punkt wirkt wie eine Quelle. Strukturell das Verhalten, das Gleichung I (∇·E = ρ/ε₀) bei verteilter Ladung beschreibt.

Rotationsfeld

F = (−y, x, 0) — zirkuliert um die z-Achse
∇·F = ∂(−y)/∂x + ∂x/∂y + ∂0/∂z
∇·F = 0 + 0 + 0 = 0

Keine Quellen, nur Wirbel — strukturell das Verhalten hinter ∇·B = 0 (Gleichung II): B-Feldlinien zirkulieren, sie entspringen nirgends.

Beachten Sie, welche Ableitung jeweils gebraucht wird: Bei ∇·F immer die Ableitung jeder Komponente nach ihrer eigenen Richtung. Beim Rotationsfeld hängt Fx = −y gar nicht von x ab — also ist ∂Fx/∂x = 0, obwohl das Feld alles andere als konstant ist. Genau daran scheitert die Intuition oft: Divergenz misst nicht, ob sich ein Feld ändert, sondern ob es auseinanderläuft.

Rotation — Wirbel oder wirbelfrei?

Dieselben zwei Felder, jetzt mit ∇× statt ∇·.

Rotationsfeld

F = (−y, x, 0)
x(∇×F)ₓ = ∂Fz/∂y − ∂Fy/∂z = 0 − 0 = 0
y(∇×F)ᵧ = ∂Fx/∂z − ∂Fz/∂x = 0 − 0 = 0
z(∇×F)_z = ∂Fy/∂x − ∂Fx/∂y = 1 − (−1) = 2
∇×F = (0, 0, 2)

Konstanter Wirbel um z — das Geschwindigkeitsfeld einer starren Rotation mit ω = 1 (allgemein: ∇×v = 2ω).

Radialfeld

F = (x, y, z)
x(∇×F)ₓ = ∂z/∂y − ∂y/∂z = 0 − 0 = 0
y(∇×F)ᵧ = ∂x/∂z − ∂z/∂x = 0 − 0 = 0
z(∇×F)_z = ∂y/∂x − ∂x/∂y = 0 − 0 = 0
∇×F = (0, 0, 0)

Wirbelfrei, wie es sein muss: F ist der Gradient von φ = ½(x²+y²+z²) — und für jeden Gradienten gilt ∇×(∇φ) ≡ 0, siehe gleich unten.

Die beiden Felder sind komplementär: Das eine hat nur Divergenz, das andere nur Rotation. Das ist kein Zufall, sondern ein tiefer Satz (Helmholtz-Zerlegung): Jedes hinreichend brave Vektorfeld lässt sich in einen quellenbehafteten und einen wirbelbehafteten Anteil zerlegen. Genau deshalb reichen ∇· und ∇×, um ein Feld vollständig festzulegen — und genau deshalb gibt es vier Maxwell-Gleichungen: je eine Divergenz- und eine Rotationsgleichung für E und B.

Zwei Identitäten, die immer gelten

Unabhängig vom Feld — beide folgen allein daraus, dass gemischte Ableitungen vertauschen (∂²/∂x∂y = ∂²/∂y∂x).

Ein Gradientenfeld ist wirbelfrei

∇×(∇φ) ≡ 0
Probe mit φ = x²y, also ∇φ = (2xy, x², 0)
z∂(x²)/∂x − ∂(2xy)/∂y = 2x − 2x = 0
x, ybeide 0, da alle beteiligten Terme verschwinden

Wozu: In der Elektrostatik ist ∂B/∂t = 0, also ∇×E = 0 nach Gleichung III. Genau deshalb darf man dort E = −∇φ schreiben und mit einem skalaren Potential (der Spannung) statt mit Vektoren rechnen.

Ein Rotationsfeld ist quellenfrei

∇·(∇×F) ≡ 0
Probe mit F = (y², z², x²), also ∇×F = (−2z, −2x, −2y)
∇·∂(−2z)/∂x + ∂(−2x)/∂y + ∂(−2y)/∂z
=0 + 0 + 0 = 0

Wozu: Weil ∇·B = 0 immer gilt, darf B stets als B = ∇×A geschrieben werden (Vektorpotential). Und: wendet man ∇· auf Gleichung IV an, erzwingt genau diese Identität die Ladungserhaltung — siehe dort.

Beide Identitäten sind keine physikalischen Aussagen, sondern reine Mathematik. Sie gelten für jedes zweimal stetig differenzierbare Feld — und sind trotzdem der Grund für zwei der wichtigsten Rechentricks der Elektrodynamik.

Werkzeug II

Zwei Integralsätze

Die drei Operatoren beschreiben, was an einem Punkt passiert. Die beiden Integralsätze übersetzen das in Aussagen über ausgedehnte Flächen und Volumina — und sind damit genau die Brücke zwischen der differentiellen und der integralen Form jeder Maxwell-Gleichung.

Gaußscher Integralsatz
∯S F·dA = ∭V (∇·F) dV
Stokesscher Integralsatz
∮C F·dl = ∬S (∇×F)·dA

In Worten: Was aus einem Volumen herausfließt, ist die Summe aller Quellen darin. Und: Was um einen Rand herum zirkuliert, ist die Summe aller Wirbel auf der eingespannten Fläche.

Warum gilt das für jedes Volumen und jede Fläche?

Die Beispiele unten prüfen die Sätze an je einem Feld nach. Der allgemeine Grund dahinter ist ein Auslöschungsargument.

Gauß: Zerlegt man das Volumen in sehr viele winzige Würfel, ist die Aussage für jeden einzelnen fast eine Definition — der Nettofluss aus seinen sechs Flächen ist (∇·F)·ΔV, genau so ist die Divergenz konstruiert. Nun addiert man über alle Würfel. Jede innere Fläche gehört zu genau zwei Nachbarwürfeln und wird zweimal gezählt, mit entgegengesetzter Flächennormale, also mit entgegengesetztem Vorzeichen. Alle inneren Beiträge löschen sich paarweise aus. Übrig bleibt nur, was keinen Nachbarn hat: die äußere Oberfläche.

Stokes: Dasselbe Argument, nur über Kanten statt Flächen. Man zerlegt die Fläche in winzige Schleifen mit gleichem Umlaufsinn; jede innere Kante wird von zwei benachbarten Schleifen in entgegengesetzter Richtung durchlaufen und hebt sich weg. Übrig bleibt die äußere Randkurve.

Deshalb ist das Ergebnis unabhängig von der gewählten Form: Man darf in Gleichung I jede beliebige geschlossene Fläche um eine Ladung legen, und in Gleichung III und IV jede beliebige Fläche in einen gegebenen Rand einspannen. Genau diese Freiheit wird bei Gleichung IV noch entscheidend — sie deckt dort eine Lücke auf, die Maxwell schließen musste.

Der Gaußsche Integralsatz am Beispiel

Das Radialfeld von oben, jetzt durch eine Kugel mit Radius R.

Volumenintegral

∇·F = 3 (siehe oben)
∫∫∫∫∫∫ (∇·F) dV = 3 · Kugelvolumen
VV = (4/3)πR³
=3 · (4/3)πR³
= 4πR³

Oberflächenintegral

Auf der Kugel: |F| = R, radial = parallel zu n̂
F·n̂F·n̂ = R (überall auf der Kugelfläche)
AA = 4πR²
=R · 4πR²
= 4πR³

Beide Seiten liefern exakt 4πR³ — für jeden Radius. Das Oberflächenintegral war hier besonders einfach, weil F auf der Kugel überall gleich lang und überall parallel zur Normalen ist: Dann wird aus dem Integral schlicht "Wert mal Fläche". Genau diese Symmetrie-Abkürzung ist der Grund, warum man in der Elektrostatik so gerne Kugelflächen wählt.

Und genau dieser Zusammenhang macht aus der differentiellen Form von Gleichung I (∇·E = ρ/ε₀) ihre integrale Form (∮∮ E·dA = Qencl/ε₀) — kein separates Postulat, sondern derselbe Satz, hier an einem einfachen Feld nachgerechnet.

Der Satz von Stokes am Beispiel

Das Rotationsfeld von oben, jetzt entlang eines Kreises mit Radius R.

Linienintegral

Kreis: r(θ) = (R cosθ, R sinθ, 0), θ ∈ [0, 2π]
FF(r(θ)) = (−R sinθ, R cosθ, 0)
dr/dθdr/dθ = (−R sinθ, R cosθ, 0)
F·dr/dθR² sin²θ + R² cos²θ = R²
∮∫₀²ᵖ R² dθ = R² · 2π
∮ F·dl = 2πR²

Flächenintegral

∇×F = (0, 0, 2) (siehe oben)
(∇×F)·n̂n̂ = ẑ, also (∇×F)·n̂ = 2 (konstant)
AKreisfläche = πR²
=2 · πR²
∬(∇×F)·dA = 2πR²

Wieder identisch, für jeden Radius. Der Rechenweg links ist die Standard-Mechanik eines Kurvenintegrals: Kurve parametrisieren, F entlang der Kurve auswerten, skalar mit dem Tangentenvektor multiplizieren, über den Parameter integrieren. Hier wird das Skalarprodukt dank sin²+cos² = 1 konstant — deshalb bleibt am Ende nur "Wert mal Umfang·R".

Das ist exakt der Schritt, der Gleichung III (∇×E = −∂B/∂t) mit ihrer integralen Form (∮E·dl = −d/dt∬B·dA) verbindet — und damit die abstrakte Punktaussage in etwas übersetzt, das man an einer realen Drahtschleife messen kann.
