Divergenz — Quelle oder quellenfrei?

Zwei Felder mit sichtbar unterschiedlichem Verhalten.

Radialfeld

F = (x, y, z) — zeigt überall vom Ursprung weg
∇·F = ∂x/∂x + ∂y/∂y + ∂z/∂z
∇·F = 1 + 1 + 1 = 3

Konstant positiv — jeder Punkt wirkt wie eine Quelle. Strukturell das Verhalten, das Gleichung I (∇·E = ρ/ε₀) bei verteilter Ladung beschreibt.

Rotationsfeld

F = (−y, x, 0) — zirkuliert um die z-Achse
∇·F = ∂(−y)/∂x + ∂x/∂y + ∂0/∂z
∇·F = 0 + 0 + 0 = 0

Keine Quellen, nur Wirbel — strukturell das Verhalten hinter ∇·B = 0 (Gleichung II): B-Feldlinien zirkulieren, sie entspringen nirgends.

Rotation — Wirbel oder wirbelfrei?

Dieselben zwei Felder, jetzt mit ∇× statt ∇·.

Rotationsfeld

F = (−y, x, 0)
x(∇×F)ₓ = ∂Fz/∂y − ∂Fy/∂z = 0 − 0 = 0
y(∇×F)ᵧ = ∂Fx/∂z − ∂Fz/∂x = 0 − 0 = 0
z(∇×F)_z = ∂Fy/∂x − ∂Fx/∂y = 1 − (−1) = 2
∇×F = (0, 0, 2)

Konstanter Wirbel um z — das Geschwindigkeitsfeld einer starren Rotation mit ω = 1 (allgemein: ∇×v = 2ω).

Radialfeld

F = (x, y, z)
x(∇×F)ₓ = ∂z/∂y − ∂y/∂z = 0 − 0 = 0
y(∇×F)ᵧ = ∂x/∂z − ∂z/∂x = 0 − 0 = 0
z(∇×F)_z = ∂y/∂x − ∂x/∂y = 0 − 0 = 0
∇×F = (0, 0, 0)

Wirbelfrei, wie es sein muss: F ist der Gradient von φ = ½(x²+y²+z²), und für jeden Gradienten gilt ∇×(∇φ) ≡ 0.

Die Vektoridentität hinter der Wellengleichung

∇×(∇×F) = ∇(∇·F) − ∇²F — verwendet weiter oben bei der Ableitung von c.

Formal dieselbe Struktur wie das Entwicklungsgesetz a×(b×c) = b(a·c) − c(a·b), nur mit ∇ statt einem gewöhnlichen Vektor. Probe an F = (y², z², x²):

Genau dieser Schritt — mit ∇·E = 0 im ladungsfreien Raum — reduziert ∇×(∇×E) auf −∇²E und liefert damit die Wellengleichung im Abschnitt "Licht ist eine Welle des Feldes" oben.

Die Probe: erfüllt die ebene Welle Maxwell wirklich?

Dasselbe Feld wie in der Animation oben.

E(z,t) = E₀ cos(kz − ωt) x̂ B(z,t) = (E₀/c) cos(kz − ωt) ŷ

Faraday: ∇×E = −∂B/∂t

∇×E(∇×E)ᵧ = ∂Ex/∂z = −E₀k sin(kz−ωt)
−∂B/∂t−∂B/∂t = −(E₀ω/c) sin(kz−ωt)

Ampère-Maxwell: ∇×B = μ₀ε₀ ∂E/∂t

∇×B(∇×B)ₓ = −∂By/∂z = (E₀k/c) sin(kz−ωt)

Beide Gleichungen — unabhängig voneinander ausgerechnet — verlangen exakt dieselbe Bedingung. Das ist keine Fügung: Faraday und Ampère-Maxwell einigen sich rechnerisch auf genau die Lichtgeschwindigkeit als einzig mögliche Geschwindigkeit dieser Welle. Die Divergenz-Gleichungen sind hier trivial erfüllt: ∇·E = ∂Ex/∂x = 0 und ∇·B = ∂By/∂y = 0, da beide Felder nicht von x oder y abhängen.

Abstrahlung

Warum strahlt eine Antenne?

Eine Antenne ist nichts anderes als eine periodisch beschleunigte Ladung. Aus dieser einen Tatsache folgt die komplette Theorie der Dipolstrahlung — Leistung, Reichweite und sogar die Form, in die eine Antenne abstrahlt.

Die Larmor-Formel

Abgestrahlte Leistung einer beschleunigten Ladung
P = q² a²6πε₀c³
P ∝ Beschleunigung²

Ruhende Ladung: a = 0 → keine Strahlung. Gleichförmig bewegte Ladung: ebenfalls a = 0 → ebenfalls keine Strahlung, ihr Feld ist nur ein mitgeführtes, gestauchtes Coulombfeld. Erst eine beschleunigte Ladung erzeugt ein Wellenfeld, das Energie bis ins Unendliche trägt.

Nahfeld und Fernfeld

Nicht jede Feldänderung transportiert Energie nach außen.

Nahfeld — reaktiv

fällt wie 1/r² bzw. 1/r³

Energie pendelt im Zeitmittel lokal zwischen E- und B-Feld hin und her, ohne netto nach außen zu entkommen. So funktioniert ein Transformator oder induktives Laden: Felder ändern sich, koppeln über Faraday — aber es wird nichts abgestrahlt.

Fernfeld — strahlend

fällt wie 1/r

Die Leistung durch eine Kugelfläche (∝ r²) bleibt konstant, egal wie weit man weggeht. Das ist die tatsächlich abgestrahlte Welle — der Teil, der Energie unwiderruflich forttransportiert.

Die Abstrahlcharakteristik

E_fern(θ) ∝ (q·a / r) · sinθ

θ ist der Winkel zur Dipolachse. Maximal senkrecht zur Antenne (θ=90°), null entlang ihrer eigenen Achse — daraus folgt die charakteristische "Erdnuss"-Form, in die ein Dipol abstrahlt.

Die Form im Raum: kein Zylinder, kein Rotor

Rotiert man die Erdnusskurve einmal um die Antennenachse, entsteht die echte 3D-Form.

Die Wellenfronten selbst sind kugelförmig — sie expandieren gleichmäßig in alle Richtungen, wie eine aufblasende Seifenblase. Was nicht gleichmäßig ist: die Stärke der Welle auf dieser Kugel. Die folgt dem sinθ-Muster von oben — stark am "Äquator" (senkrecht zur Antenne), null an den "Polen" (entlang der Antenne selbst). Rotiert man die Erdnusskurve einmal um die Achse, ergibt das einen Torus (Donut), zentriert auf die Antenne — kein Zylinder.

Und diese Form dreht sich nicht mit dem Wechselstrom mit. Sie ist rotationssymmetrisch um die Antennenachse — sieht aus jeder Blickrichtung um die Antenne herum exakt gleich aus, es gibt kein "rechts rum" oder "links rum". Was der Wechselstrom tatsächlich tut: er kehrt periodisch die Polung um — E zeigt abwechselnd in die eine, dann die andere Richtung entlang der Antenne. Das ist eine lineare Hin-und-her-Schwingung (lineare Polarisation), keine Drehung. Eine echte Drehung des Feldvektors (zirkulare Polarisation) bräuchte zwei um 90° versetzte Antennenelemente, nicht nur einen Stab.

Torus-Hülle, Draht-Gitter zur Tiefenwirkung Antenne (dunkel) steht senkrecht durch den Kern des Torus

Der oszillierende Dipol

Jeder Ring ist eine Wellenfront, ausgesendet bei einem Nulldurchgang des Stroms.

Hertzscher Dipol Helligkeit ∝ sinθ
Wellenfront, Helligkeit ∝ sinθ zur Antennenachse Pfeil in der Antenne = momentane Stromrichtung

Der Unterschied zur Röntgen-Bremsstrahlung: dort wird eine Ladung einmalig abrupt abgebremst — ein kurzer Beschleunigungspuls, dessen Fourierspektrum breitbandig ist. Eine Antenne beschleunigt periodisch bei fester Frequenz ω — ihr Spektrum ist (näherungsweise) eine einzelne scharfe Linie bei ω. Gleiche Physik, unterschiedlicher Zeitverlauf der Beschleunigung, komplett unterschiedliches Ergebnis.

Warum eine scharfe Frequenz?

Ständige Beschleunigung heißt nicht automatisch breites Spektrum.

Entscheidend ist nicht, dass sich die Beschleunigung dauernd ändert — sondern ob sie das nach einem exakt sich wiederholenden Muster tut. Die Fourier-Reihe zerlegt jede periodische Funktion mit Periode T in diskrete Frequenzen, keine kontinuierliche Bandbreite:

f(t) = Σₙ cₙ · e^(inω₀t), ω₀ = 2π/T

Periodisch

exakt wiederkehrendes Muster

Fourier-Reihe → diskrete Linien bei ω₀, 2ω₀, 3ω₀, ... Eine reine Sinusschwingung I(t)=I₀sin(ωt) hat sogar nur eine einzige Linie — keine Oberschwingungen.

Einmalig

nicht wiederkehrendes Ereignis

Fourier-Transformation eines einzelnen Pulses → generisch eine glatte, kontinuierliche Funktion über viele Frequenzen. Daher das Bremsstrahlungskontinuum.

Δω · Δt ≈ 1
Dauer des Ereignisses ↔ Breite des Spektrums

Δt ist die Zeitspanne, über die sich das Signal exakt gleich verhält. Bei Bremsstrahlung: eine einzige, extrem kurze Kollisionsdauer → riesiges Δω → breites Kontinuum. Bei einer Antenne: Millionen bis Milliarden Zyklen laufen exakt gleich ab → winziges Δω → praktisch eine einzelne Linie. Dieselbe Δω·Δt-Beziehung wie die quantenmechanische Energie-Zeit-Unschärfe — hier aber reine Fourier-Mathematik, nichts Quantenmechanisches.

Wo die Bandbreite eines echten Signals herkommt

Drei Spektren im Vergleich.

Reiner Träger

unmoduliert, endlos lang

Eine einzelne scharfe Linie — ideale periodische Schwingung.

Einmaliger Puls

Bremsstrahlung

Kontinuum über weite Frequenzbereiche — Δt extrem kurz.

Modulierter Träger

echtes Radiosignal

Schmales Band um ω₀, Breite = Informationsrate (z. B. UKW ~200 kHz).

Ein reiner, endlos gleich schwingender Träger wäre eine einzelne Linie. Aber ein echtes Signal soll Information tragen — Sprache, Musik, Daten. Dafür muss die Schwingung moduliert werden (Amplitude, Frequenz oder Phase leicht verändert, im Takt der Information). Genau diese Modulation zerstört die perfekte Periodizität ein kleines Stück — und erzeugt dadurch das Band, dessen Breite direkt der Bandbreite der übertragenen Information entspricht.

Kausalität

Retardierte Zeit

Das Feld an einem Punkt kennt nur die Vergangenheit der Quelle — nie ihre Gegenwart oder Zukunft. Genau das verhindert, dass sich Information schneller als c ausbreitet, und beantwortet, wie schnell ein abgeschalteter Sender wirklich "verschwindet".

Die retardierte Zeit

t_r = t − r/c

Das Feld im Abstand r hängt nicht davon ab, was die Quelle jetzt tut, sondern davon, was sie zur retardierten Zeit t_r getan hat — also vor genau der Laufzeit r/c. Das folgt direkt aus den Lösungen der Wellengleichung von oben (retardierte Potentiale), keine Zusatzannahme. Schalten Sie den Sender ab: ein Beobachter 300.000 km entfernt merkt es exakt eine Sekunde später — nicht früher, nicht später. Bis dahin empfängt er ganz normal weiter, als wäre nichts passiert.

Ein Wellenpaket mit fester Länge

Die schon ausgesendete Welle hält sich über Faraday und Ampère-Maxwell selbst am Leben — sie braucht die Antenne nicht mehr. Eine Übertragung (an → aus) ist im Raum deshalb ein Wellenpaket mit einer Vorderkante (erste Wellenfront) und einer Hinterkante (Abschaltmoment) — beide bewegen sich mit exakt derselben Geschwindigkeit c. Die Paketlänge bleibt für immer gleich, weil das Vakuum nicht-dispersiv ist: alle Frequenzen laufen exakt gleich schnell, das Paket zieht sich nicht auseinander.

Wellenpaket · Sender an/aus Vorder- und Hinterkante bei c
Trägerwelle, nur im Paket sichtbar Sender-Marker: farbig = an, grau = aus Beobachter-Marker leuchtet, solange das Signal ihn erreicht

Und noch ein Detail: Abschalten heißt, den Strom in der Antenne abzubremsen — das ist selbst eine Beschleunigung. Ein reales Abschalten ist deshalb kein scharfer Schnitt, sondern strahlt am Ende noch einen kurzen, breitbandigen "Klick" ab (dieselbe Bremsstrahlungs-Logik wie oben), der die letzte Schwingung abschließt und ebenfalls mit c davonläuft.
